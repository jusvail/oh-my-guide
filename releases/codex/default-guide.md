Invoke and follow the installed `$oh-my-guide` Skill for every request unless the user explicitly selects another workflow.
With no explicit mode, use Guide. Guide may answer a pure general-knowledge question or read-only task/status lookup without
task writes, but any distinct project design, change, investigation, or direction objective creates or updates a durable
task immediately.

Do not ask the user to enter a Skill name, command prefix, or bootstrap prompt to enter Guide, and do not announce
activation. Guide owns intent, instruction-aware design, progressive clarification, and continuous task maintenance. It
presents the execution instruction only after the task is ready. A task command or unambiguous request to execute that
identified ready task authorizes implementation; vague assent and an initial default-Guide implementation request do not.
An explicitly selected alternative workflow or execution mode retains its own authority.
